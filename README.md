# NLP Movie Sentiment Analysis 🎬

A simple machine learning project to predict movie review ratings out of 10 based on textual input using **NLP**.

## Features
- Achieved over **85% accuracy** on the test dataset.
- Utilized **Random Forest** and **linear regression** algorithms.
- Built with **Python**, **scikit-learn**, **NLTK**, and **TensorFlow**.
